# Запуск среды разработки виджетов Insight + ИИ-ассистент Kilo Code

Инструкция для тех, у кого есть доступ в интернет и кто хочет
использовать более мощные модели, чем в офлайн-варианте — без
собственной подписки и без регистрации.

Вам прислали **`insight-widgets-client-package.zip`** (~380MB, без
модели — она не нужна, ИИ работает через облако).

---

## Что за ИИ и чего от него ждать

Kilo Code — расширение VS Code с доступом к бесплатным облачным
моделям через собственный шлюз. Важно понимать:

- **Это не офлайн.** Запросы уходят через интернет на серверы Kilo
  Code и дальше — к провайдеру конкретной модели. Если нужна работа
  без интернета и без передачи данных за пределы компьютера — это не
  тот вариант, см. инструкцию с локальной моделью (Docker + Ollama).
- **Регистрация не требуется** для бесплатных моделей — работает
  анонимно.
- **Есть лимит: ориентировочно 200 запросов в час на IP-адрес.** Это
  не «безлимит» — при интенсивной работе или если несколько человек
  сидят с одного офисного IP, лимит может закончиться быстрее, чем
  кажется.
- **Список бесплатных моделей меняется со временем** — Kilo Code сам
  переключает, какая конкретно модель обрабатывает запрос. Нельзя
  рассчитывать, что через месяц будет доступна ровно та же модель, что
  и сегодня.
- По качеству бесплатные облачные модели, как правило, заметно сильнее
  локальной 14B-модели из офлайн-варианта — это более крупные модели
  от реальных провайдеров.

## Что нужно установить заранее

- **Docker Desktop**: [docker.com/products/docker-desktop](https://www.docker.com/products/docker-desktop/)
- **Visual Studio Code**: [code.visualstudio.com](https://code.visualstudio.com/)
  — устанавливается как отдельная программа.

## Шаги запуска

**Шаг 1.** Распакуйте `insight-widgets-client-package.zip` в рабочую
папку.

**Шаг 2. Откройте VS Code** → `File` → `Open Folder` → выберите
распакованную папку.

**Шаг 3. Откройте терминал внутри VS Code** (используется встроенный
терминал VS Code, а не отдельное окно PowerShell/Terminal): меню
`Terminal → New Terminal`, либо `` Ctrl+` `` (Windows) / `` Cmd+` ``
(Mac).

**Шаг 4. В терминале выполните:**
```
docker load -i insight-widgets.tar.gz
docker compose up
```

**Шаг 5.** Дождитесь строки:
```
App running at: Local: http://localhost:3001
```
Терминал не закрывайте — там работает dev-сервер. Если порт `3001`
занят чем-то другим — поменяйте `"3001:3001"` на, например,
`"3002:3001"` в файле `docker-compose.yml` и используйте
`localhost:3002` дальше.

## Установите расширение Kilo Code в VS Code

1. Откройте панель **«Расширения»** (значок в левой боковой панели).
2. Найдите **Kilo Code**, нажмите **Install**.
3. При первом запуске выберите использование бесплатных моделей
   (обычно предлагается вариант вроде «Kilo Auto Free») — создавать
   аккаунт для этого не нужно.

## Как этим пользоваться

Боковая панель Kilo Code — интерфейс чата с ИИ. Задача формулируется
текстом в поле внизу панели, дальше — кнопка отправки. Примеры
запросов:

> Создай виджет ElemHelloWorld по образцу ElemButton

> Объясни, что делает этот файл

> Добавь виджету настройку цвета текста

ИИ предложит код или правки — результат следует проверять перед
применением, как и в случае с любым ИИ-ассистентом.

**Правила проекта.** В репозитории есть свод правил разработки
виджетов — `widget.mdc`, `WIDGET_REFACTORING_SPEC.md` и
`docs/ai-playbook/ai-playbook-summary.md`. Модель не подключает их
автоматически, поэтому при обращении к ИИ указывайте путь к файлу
правил прямо в запросе, например:

> Создай виджет ElemHelloWorld по образцу ElemButton, следуя правилам
> из docs/ai-playbook/ai-playbook-summary.md

Без этого модель будет ориентироваться только на код в открытых
файлах и может не учесть требования проекта (структуру каталогов,
`propChanged`, формат размерных пропсов и другие обязательные
паттерны).

## Подключение виджета к редактору платформы (`$elem.add`)

Когда виджет готов и dev-сервер запущен (`http://localhost:3001` из
шага 5):

1. Откройте в браузере страницу редактора платформы Insight, зайдите в
   свой проект.
2. Откройте консоль разработчика: `F12` → `Console`.
3. Выполните:
   ```js
   $elem.add({
       types: ['ElemHelloWorld'],
       url: 'http://localhost:3001'
   });
   ```
   (`types` — имя вашей папки в `./src`).

Виджет появится на панели инструментов редактора.

`$elem.remove()` в той же консоли отключает подключённые виджеты
(после — обновите страницу редактора).

## Пересборка / перезапуск

Если после создания **нового** виджета он не подхватился (dev-сервер
иногда не сразу замечает только что созданные файлы, в отличие от
правок в существующих) — в терминале, где выполняется `docker compose
up`, нажмите `Ctrl+C`, затем:
```
docker compose down
docker compose up
```
Это пересоздаёт контейнер и гарантированно подхватывает все текущие
файлы проекта.

## Частые проблемы

| Проблема | Решение |
|---|---|
| `Cannot connect to the Docker daemon` | Docker Desktop не запущен — откройте приложение, дождитесь, пока значок кита в трее перестанет анимироваться |
| `port is already allocated` | Порт `3001` занят — смените на `3002:3001` в `docker-compose.yml`, используйте `localhost:3002` |
| Kilo Code отвечает ошибкой о превышении лимита запросов | Бесплатный лимит (~200 запросов/час на IP) исчерпан — подождите или переключитесь на офлайн-вариант с локальной моделью |
| Модель отвечает не так, как ожидалось / хуже, чем раньше | Список бесплатных моделей меняется без предупреждения — это ожидаемое поведение бесплатного тарифа |
| `$elem` не определён в консоли браузера | Обновите страницу редактора — объект создаётся при загрузке страницы |
| Виджет не появился после `$elem.add` | Проверьте, что `types` совпадают с именами папок в `./src`, и что `url` открывается в браузере напрямую |

При возникновении проблем, не описанных выше, приложите текст ошибки в
исходном виде (скриншот или копию из терминала/консоли браузера) — это
ускорит диагностику.
